## CMIN2 是什么？和普通 CMI 差在哪

CMIN2 是中国移动的精品国际骨干网（China Mobile International Next-generation Network），ASN 编号 AS58807，可以理解成“移动版的 CN2 GIA”：独立专用通道，带宽利用率控制在 80% 以下，晚高峰不挤。而常见的 CMI（AS58453）是移动的常规国际出口，覆盖广但晚高峰容易拥堵，不少便宜套餐宣传的“移动直连”走的就是这条普通线路。

两者用 ASN 一看便知：回程路由里出现 AS58807 是精品 CMIN2，AS58453 则是普通 CMI。

在 CMIN2 接入之前，移动用户买搬瓦工只能蹭电信的 CN2 GIA——那是电信的线路，移动流量要先绕路接入，晚高峰延迟和丢包都难看。CMIN2 上线后，移动用户有了自己的专属通道，体验才真正和电信用户对齐。

## 如何验证自己的 VPS 走了 CMIN2

最直接的办法是用 NextTrace 跑一次回程路由，看有没有 AS58807 或 223.118.x.x / 223.119.x.x 的节点。

NextTrace 是开源路由追踪工具，GitHub 项目页（NTrace-core）提供各平台的单文件程序，下载后放到 /usr/local/bin/ 目录即可。之后两步：


chmod +x /usr/local/bin/nexttrace
nexttrace 223.5.5.5


输出里回程节点出现 223.118.x.x 或 223.119.x.x，或者 ASN 显示 AS58807，就说明 CMIN2 已生效。懒得跑命令的话，KiwiVM 面板里机房描述会直接标注 CN2GIA、CMIN2、CUP 字样，选机房时看这里就能确认。

## 常见问题

**便宜套餐宣传的“移动直连”是 CMIN2 吗？**

**CMIN2 和 CN2 GIA 是二选一吗？**
不是，两者同时存在：CN2 GIA 管电信方向，CMIN2 管移动方向，联通走 CUP（AS9929）。选 DC6/DC9 一次性全都有。
